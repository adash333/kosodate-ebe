## 対応内容

### 1. ポリシー総点検（doc/adsense-policy-scan-20260824.md）

記事50本・用語解説53本・動画データ169件・法務ページをリスク語で全文スキャンし文脈精読。
m.5micro.net の本番ページもクロール検証。検出は R1〜R5（詳細はレポート参照）。

### 2. kosodate-ebe 側の修正（コミット 75e8f63）

- 動画023「運動でうつ病が治る」→「運動とうつ症状の改善」。finding から「抗うつ薬と同程度」を
  外し、advice を「気分の落ち込みが続くときは専門家に相談を」に変更
- 動画170「ASDの不安症はCBTで治る」→「ASDの子の不安にCBTが役立つ」
- karada-anzen の引用書名を『おうち性教育はじめます』に短縮（副題の「SEX」表記を除去）
- **注意**: この環境では `npm run data` を使わないこと。`build-data.mjs` が vault 不在のため
  `_raw_extract.json` を空にする。`node scripts/merge-data.mjs` のみ実行する

### 3. myopia-forecast 側の修正（コミット b3316c2）

- 処方薬・費用系6ページ（atropine / atropine-drug / misight-atropine / ryjusea-sentei-ryoyo /
  prescriber-requirements / cost）で adsbygoogle スクリプトと記事末広告を停止
  （`lib/ads.ts` の `AD_EXCLUDED_PATHS`＋`components/AdSenseScript.tsx` 新設）
- /guide/atropine のタイトル・h1・画像altを一般名化。「1箱4,000〜5,000円」を
  「受診先にご確認ください」に変更（具体額は出典つきの /guide/cost に集約）
- トップページの Amazon アソシエイト枠を撤去（記事内の書籍紹介は維持）
- テスト4件追加（93件全緑）、REQUIREMENTS.md に恒久ルール追記、draft に経緯記録
- **本番反映は VM 側の daily-deploy.sh（Cloud Run）実行後**

### 4. 悩み別ガイド /consult 新設（8/11監査の残項目・コミット別）

- taxonomy.json のサブカテゴリ32件それぞれに /consult/:id の固有ページを新設
- 構成: 書き下ろし解説2〜3段落（`src/consult.ts`）＋関連論文解説カード3枚＋
  関連する読み物・用語解説・同カテゴリ他テーマへの内部リンク＋相談窓口の注記
- 発達特性・不安のページは診断的記述を避け、健診・かかりつけ医・自治体窓口への案内を明記
- 導線: ヘッダーナビ「悩み別」、トップページ、404ページ、3タップ結果画面
- プリレンダリング 113→147ページ、sitemap 146URL
