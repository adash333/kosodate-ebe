# 260811-01 AdSense審査対策一括実施

**相談日**: 2026年8月11日

> Google AdSenseの審査に通りたいです。（監査レポート adsense-audit-5micro-20260811.md を添付）
> 適切な場所に保存して、このファイルを参考に、サイトを修正したいです。必要なことは私に聞いてください。順番に修正をお願いします。

## 対応内容

監査レポートを [doc/adsense-audit-5micro-20260811.md](../adsense-audit-5micro-20260811.md) に保存し、レポートのステップ1・2をすべて実施した。

### ステップ1（最優先修正）

- **1-1** AdSense自動広告コードを index.html の head に設置（ca-pub-6024571063221724）
- **1-2** /author の404を解消：entry-server.tsx のプリレンダリング対象に追加、sitemap.xml にも掲載
- **1-4** 用語解説53語の扱いはユーザー選択で **B案（全ページ加筆）**。5バッチのサブエージェントで全53語を加筆し、平均562字 → 1,661字（全語1,601〜1,752字）。構成は「定義／研究でわかっていること（限界含む）／家庭での例／よくある誤解」。医療系用語（ASD・ADHD・LD等）はYMYL配慮で診断的記述を避け相談窓口への導線を明記。言及研究は実在の著名研究のみ
- **2-5** /search に noindex を付与し sitemap から除外（PageMeta に noindex フラグ追加）

### ステップ2

- **2-2** 全ページのタイトル見出しを h2 → h1 に変更（11箇所）
- **2-3** ヘッダーに常設グローバルナビ（読み物／用語解説／動画／執筆者）を追加
- **2-4** 専用404ページを新設（NotFound コンポーネント＋dist/404.html をプリレンダリング、copy-404.mjs は廃止）
- **2-7** canonical・og:url・sitemap を実URL（末尾スラッシュあり）に統一
- **1-5** /videos のページ送りを /videos/page/N の実URL（aタグ）化しプリレンダリング＋sitemap追加（全169件がクロール可能に）。3タップ相談室の結果カードに自サイトの関連記事・用語解説へのリンクを追加
- **1-3** ヒーロー画像94枚を PNG（約2.4MB）→ WebP 1200×675（約60〜90KB）に一括変換（scripts/optimize-images.mjs 新設、sharp を devDependency に追加）。img に width/height/decoding/fetchpriority を付与
- **2-6** og:image を全ページに設定（記事・用語はヒーロー画像、その他はサイト既定の /ogp.png を新規生成）。twitter:card を summary_large_image に。トップに WebSite、用語ページに DefinedTerm の JSON-LD を追加
- **2-9** 執筆者ページに「執筆の背景」（夫婦ともに東大理三出身の医師・医学博士）を追記。専門科・所属学会はブログでも非公開のため記載せず（ユーザーの指定によりブログ risan.jpn.org / i-doctor.sakura.ne.jp/font/ の公開情報の範囲で作成）

### 効果（ビルド後の実測）

- プリレンダリング 103ページ、sitemap 102URL（/author 追加・/search 除外・動画ページ送り3URL追加）
- 用語解説ページの実質テキストは2,000字超（例: self-esteem 2,082字）
- 画像総容量 199MB → 7.8MB、dist 全体 11MB
