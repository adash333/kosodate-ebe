# 260811-02 Search Console再送信とインデックス登録手順

**相談日**: 2026年8月11日

## ユーザー依頼

> 順番にやりたいです。まず、１（Search Console で sitemap を再送信しインデックスを確認）について具体的手順について教えてください

## 対応内容

### 事前確認（本番反映チェック）

curl で本番サイトを確認し、以下を確認済み：

- `https://5micro.net/author/` → HTTP 200（404解消済み）
- `sitemap.xml` → 102 URL（`/author` あり・`/search` なし）
- トップページに AdSense コード（adsbygoogle）配信済み

### 案内した手順

- **A. sitemap 再送信**: Search Console「インデックス作成 → サイトマップ」で `sitemap.xml` を再送信。検出URLが 99 → 102 件になれば成功
- **B. 重要ページのインデックス登録リクエスト**: URL検査から優先順に申請。最優先は `/author/`、次点 `/glossary/`・加筆済み用語ページ代表・`/videos/page/2/`。上限はプロパティごとに1日10〜12件程度
- **C. 経過確認（週1回・2〜4週間）**: 「インデックス作成 → ページ」で登録済み件数の増加、`/author/` の登録、`/search` が noindex 除外に入るのは正常、を確認
- **D. 再申請タイミング**: インデックス安定後（2〜4週間後）に AdSense 再申請

### 実施結果（ユーザー報告・スクリーンショット）

- sitemap 再送信完了：**ステータス「成功しました」・検出102ページ** ✅
- B のインデックス登録リクエストを実施中

### 途中で判明した課題（今後の対応候補）

1. **a.5micro.net / y.5micro.net** が robots.txt 取得失敗（5xx）でインデックス登録不可 → サーバー／DNS設定の修正が必要。リポジトリ・ホスティング場所は未確認
2. **m.5micro.net/guide/pal** の Google 選定正規URLが無関係な外部サイト（marcustheatres.com）になっている → canonical タグ未出力＋本文が薄いことが原因の可能性。手順4（m.5micro.net 対応）のときに全ページ canonical 明示と該当ページ加筆をあわせて実施予定
