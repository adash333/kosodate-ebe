# Google AdSense 審査 事前診断レポート

- 対象サイト: https://5micro.net/ （子育てエビデンス相談室）
- 追加審査希望: https://m.5micro.net/ （子どもの近視ナビ／近視進行予測シミュレーター）
- 診断日: 2026-08-11
- 診断方法: 全ページのクロール（sitemap 掲載 URL 全件のHTTPステータス確認）、生HTML（クローラーが見る状態）の検証、本文文字数の実測、画像・スクリプト容量の実測、モバイル表示確認

## 0. 結論（サマリー）

| サイト | 現状の合格見込み | 最大の障害 |
|---|---|---|
| 5micro.net | △（やや低い。ただし修正は容易） | AdSenseコード未設置 ／ 主要ページが404 ／ 薄いページが全体の半数以上 |
| m.5micro.net | ○（コンテンツ面は良好） | 医療YMYLとしてのE-E-A-T（監修者の明示）不足 ／ 運営者情報が簡素 |

意外に思われるかもしれませんが、コンテンツの「質」そのものは 5micro.net より m.5micro.net のほうが AdSense 的には整っています。
5micro.net は記事本文の品質は高いのに、技術的な不備と『薄いページ・外部リンク集』が全体の印象を大きく下げている状態です。

## 1. 最優先で修正すべき項目（これを直さないと通りにくい）

### 1-1. 【最重要】5micro.net に AdSense コードが1行も入っていない

トップ、記事、会社情報、プライバシーポリシーの生HTMLを全て確認しましたが、adsbygoogle のスクリプトも自動広告コードも存在しませんでした。
一方 m.5micro.net には設置済みです（同じ pub-6024571063221724）。

- ads.txt は両ドメインとも正しく設置済み（google.com, pub-6024571063221724, DIRECT, f08c47fec0942fa0）
- しかし審査では『広告コードが貼られたページ』をクローラーが確認します。未設置のまま申請すると、審査が進まない／不合格が繰り返される典型パターンです。

対応: AdSense管理画面で発行される自動広告スクリプトを、全ページの head 内に設置してから再申請してください。SPA（Vite）構成なので index.html のテンプレートに入れれば全ページに反映されます。

### 1-2. 【重要】/author（執筆者について）が HTTP 404 を返している

これは今回いちばん見つけにくい、そして致命的な不具合です。

- 全ページのフッターに『執筆者について』としてリンクされている
- ブラウザでは正常に表示される（JavaScriptで描画されるため）
- しかしサーバーの応答は 404 Not Found、生HTMLはトップページの雛形のみ
- sitemap.xml にも /author が含まれていない

つまり Googlebot / AdSense のクローラーから見ると、『全ページから貼られている執筆者紹介ページが存在しない（リンク切れ）』状態です。
E-E-A-T（専門性・権威性・信頼性）の中核となるページが 404 なので、YMYL寄りの子育て・医療情報サイトとしては相当な減点になります。

対応: プリレンダリング対象のルート一覧に /author を追加し、sitemap.xml にも追加してください。他の99URLは全て正常（200）だったので、設定漏れは /author だけです。

### 1-3. 【重要】記事のヒーロー画像が1枚あたり約2.4MBのPNG

実測値: kamitsuki.png 2,352KB / toenshiburi.png 2,444KB / hoikuen.png 2,443KB / screen-baby.png 2,384KB / self-control.png 2,370KB

さらに img タグに width / height / loading 属性が一切ありません。
モバイル回線では表示に数秒〜十数秒かかり、LCP（表示速度）とCLS（レイアウトのずれ）が大きく悪化します。
AdSenseの審査員は実際にスマホで閲覧するため、『ユーザー体験が悪いサイト』と判断される要因になります。

対応:
- PNG → WebP または AVIF に変換（幅1200px程度、目標100〜250KB）。容量は10分の1以下になります
- img に width / height を明示（CLS対策）
- 記事上部の1枚目は fetchpriority=high、それ以降は loading=lazy

### 1-4. 【重要】用語解説53ページが薄く、サイト全体の『低品質』判定を招いている

実測した本文ボリューム（HTMLタグ除去後、ナビ・フッター込み）:

| 区分 | 件数 | 平均文字数 | 1,000字未満 | 1,500字未満 |
|---|---|---|---|---|
| 読み物（記事） | 37本 | 約2,485字 | 0本 | 0本 |
| 用語解説 | 53本 | 約1,089字 | 33本 | 46本 |

ナビ・フッターの定型文（300〜400字）を引くと、用語解説の実質本文は多くが600〜700字程度です。
インデックス対象ページの過半数（53/99）が薄いページという構成は、『価値の低い広告枠：コンテンツが不十分』の判定に直結しやすい状態です。
記事37本の質は高いだけに、この53ページが足を引っ張っています。

対応（どちらかを選択）:
- A案（推奨・安全）: 用語解説を当面 noindex にし、sitemap から外す。ユーザー向けには残したまま、審査対象からは外す
- B案（時間はかかるが理想）: 各用語を1,500〜2,500字に加筆（定義／研究の背景／家庭での例／関連する誤解／出典）
- C案: 関連の近い用語を統合し、1ページあたりの情報量を増やす（例: ASD・ADHD・LD・ギフテッド・HSP を『発達特性の用語まとめ』に集約）

### 1-5. 【重要】/videos が実質『外部リンク集』になっている

- 全169件の一覧で、各項目は1行の要約＋『解説動画』（YouTube）＋『論文解説』（risan.jpn.org）の外部リンクのみ
- 1ページに約112本のリンクがあり、その大半が外部
- ページ送りが a タグではなく button 実装のため、2〜4ページ目はクローラーから到達不可（169件中、約50件しか認識されない）
- トップの『3タップ相談室』の最終結果画面も、リンク先は YouTube と risan.jpn.org のみで、自サイトの記事へ誘導していない

AdSenseから見ると、サイトの主要機能が『他社サービス（YouTube）と別ブログへの送客』になっており、
『独自の価値あるコンテンツが乏しい』『他サイトへの誘導が主目的』と評価されるリスクがあります。

対応:
- 3タップの結果カードに、必ず自サイト内の関連記事・用語解説へのリンクを追加する（内部回遊を作る）
- /videos のページ送りを a タグ（/videos?page=2 等の実URL）にして全件クロール可能にする
- 各動画テーマに数百字の独自解説を添える、または動画一覧を当面 noindex にする

## 2. 中〜低優先度の改善点（5micro.net）

### 2-1. 3タップ相談室に固有URLがない
カテゴリ選択から結果表示まで、全て『/』のまま遷移します。サイトの目玉機能なのに、クローラーからはトップページ1枚（生HTML約1,580字）にしか見えていません。
『/consult/kanshaku』のように悩み別の固有URLを持たせ、そこに独自解説を載せると、良質なページを数十枚追加できます。

### 2-2. 記事ページに h1 がない
記事タイトルが h2 で、h1 が0個です（見出し構成は h2 → h3 × 7）。タイトルは h1 にしてください。

### 2-3. グローバルナビゲーションがない
ヘッダーにはロゴのみで、メニューはフッターだけです。審査では『分かりやすいナビゲーション』が明示的に評価項目になっています。
ヘッダーに「読み物／用語解説／動画／執筆者について」を常設してください。

### 2-4. 404ページがトップページの内容を表示している
ステータスコード自体は正しく404を返しますが、表示内容はトップページの雛形です。専用の404ページ（お探しのページは見つかりません＋記事一覧・検索への導線）を用意してください。

### 2-5. サイト内検索ページ（/search）が sitemap に含まれている
検索結果ページは noindex にし、sitemap から除外するのが定石です（実質161字の空ページとして認識されています）。

### 2-6. 構造化データ・OGPの不足
- 記事ページには JSON-LD あり（良い）
- 用語解説・一覧・トップには JSON-LD なし
- og:image が全ページで未設定（SNS共有時に画像が出ません）
- 記事の JSON-LD に author / publisher / datePublished / dateModified が入っているか再確認を

### 2-7. canonical と実URLの表記ゆれ
実際のURLは末尾スラッシュあり（例 /glossary/attachment/）ですが、canonical は末尾スラッシュなしを指しています。301で解決はしますが、統一しておくのが安全です。

### 2-8. www.5micro.net が未設定
DNSが解決しません。重複の心配はありませんが、名刺やSNSでwww付きを案内する予定があるなら設定を。http → https のリダイレクトは正常に動作しています。

### 2-9. 執筆者の匿名性
『りさお（医師・医学博士）』というハンドルネームのみで、実名・所属・医籍情報の記載がありません。
法人（合同会社5マイクロ／住所記載あり）が明示されている点は評価できますが、子育て×医療というYMYL領域では、
実名か、少なくとも『専門科・経験年数・所属学会』程度の追加情報があると信頼性が上がります。

## 3. 5micro.net の良い点（審査でプラスに働く部分）

- 記事37本がすべて独自執筆で、平均2,500字前後。出典（Tremblay 2004、NICHD、AAP、WHO など）を明記し、Google Scholar へのリンクも付与
- 断定を避け、研究の限界にも触れる中立的な書き方。子育て情報にありがちな煽りがない
- 全記事に免責事項（診断・治療の代替ではない旨、専門機関への相談案内）を掲載
- 記事末尾に執筆者プロフィール枠あり（ただし1-2のとおりリンク先が404）
- プライバシーポリシーが非常に丁寧（GA4・AdSense・DoubleClick Cookie・オプトアウト方法・13歳未満の扱い・保管期間まで記載）
- 免責事項、運営者情報（法人名・住所・事業内容）、問い合わせフォーム（ハニーポット付き）が揃っている
- sitemap 掲載の99URLすべてが HTTP 200（/author のみ例外）
- HTTPS、レスポンシブ、viewport 設定、画像の alt テキストも適切
- プリレンダリング済みでクローラーが本文を読める（SPAにありがちな空HTML問題は回避できている）
- 記事の更新日が管理されており、一部記事は追記更新されている

## 4. m.5micro.net（子どもの近視ナビ）の診断

### 4-1. 現状

- sitemap 掲載54URL すべて HTTP 200、薄いページ（実質800字未満）はゼロ
- guide 配下に約45本の解説記事（近視とは／治療法／アトロピン／オルソK／ミヨスマート／ステレスト／合併症／費用／生活習慣 など）
- ヘッダーに7項目のグローバルナビ、フッターに運営者情報・プライバシー・免責
- AdSenseコード設置済み、ads.txt 設置済み、JSON-LD あり、canonical あり、sitemap に lastmod あり
- 記事末に参考文献（LAMP study、COMET、Jones-Jordan 2021 など）を明記
- 予測ツールの入力値はブラウザ内計算でサーバー送信なし、とプライバシーポリシーに明記（好印象）
- Amazonアソシエイト参加の表記あり

技術面・分量面では 5micro.net より整っており、単体で審査に出しても土俵には乗るレベルです。

### 4-2. ただしYMYL医療サイト特有のリスクがある

1. 監修者が不明。/about には『合同会社５マイクロ』とあるだけで、医師名・眼科医の監修表記・所在地・連絡先住所がありません。5micro.net 側にある会社情報レベルの記載を、こちらにも入れるべきです。医療情報で監修者不在は最大の減点要因です。
2. 処方薬・自由診療の扱い。『リジュセアミニ（0.025%アトロピン）』という具体的な製品名、効果、費用（1箱4,000〜5,000円）に踏み込んでいます。教育目的の解説であれば方針違反ではありませんが、AdSenseの医薬品関連ポリシーおよび日本の医療広告ガイドライン・薬機法の観点から、『特定製品の推奨』と読まれない表現に整えるのが安全です。
3. 個別予測を出すシミュレーター。年齢と度数から18歳時点の度数と治療による抑制量（例: 約0.69D）を数値で提示します。注意書きはありますが、『医療上の予測を提供するツール』と見なされると審査は厳しくなります。結果画面の冒頭（数値より上）に、赤字レベルで目立つ免責を置くことを推奨します。
4. 眼科リスト225件・眼鏡店リスト。各院の公式サイトから集めた対応状況の一覧です。独自の確認日・注記が付いている点は良いのですが、外部情報の集約ページとして『独自性が低い』と見られる可能性があります。また医療機関の一覧は医療広告ガイドラインに触れないよう、比較・推奨のニュアンスを避けてください。情報の鮮度管理（確認日2026-06-19が大半）も継続が必要です。
5. 問い合わせフォームが /about 内にあるだけで、独立した『お問い合わせ』ページがありません。

### 4-3. m.5micro.net の改善アクション

- /about に、法人名・所在地・代表者・連絡手段・監修者（眼科医または医師の氏名と資格）を明記する
- 全 guide 記事に『監修: ○○（眼科専門医）』と最終更新日を表示する
- 独立した /contact ページを作る
- 予測結果の直上に免責を配置し、『参考値であり診断ではない』ことを視覚的に強調する
- 特定製品名を見出しから外し、一般名（低濃度アトロピン点眼）を主にする
- 眼科リストは『広告ではなく公開情報の整理である』旨と、更新ポリシーを明記する

## 5. AdSense申請の進め方（推奨手順）

重要: 5micro.net と m.5micro.net は、サイトの主題も読者層も別物です（子育て全般／子どもの近視という医療テーマ）。同時に出すより、順番に進めるのが安全です。

ステップ1（今すぐ・1〜2日）
- 5micro.net に AdSenseコードを設置
- /author の404を修正し、sitemap に追加
- 用語解説53ページを一旦 noindex にする（または加筆計画が終わるまで sitemap から外す）
- /search を noindex にする

ステップ2（1週間程度）
- 記事画像をWebP化し、width/height/loading を付与
- ヘッダーにグローバルナビを追加
- 記事タイトルを h1 に変更
- 3タップ結果カードに自サイト記事への内部リンクを追加
- 専用404ページを作成

ステップ3
- Search Console で sitemap を再送信し、主要ページがインデックスされていることを確認
- インデックスが安定したら 5micro.net で再申請

ステップ4（5micro.net の結果が出てから）
- m.5micro.net の監修者情報・免責強化を実施
- AdSense管理画面の『サイト』から m.5micro.net を追加して申請

補足: 短期間に何度も再申請を繰り返すのは逆効果です。修正を全て終え、Googleに再クロールされる時間（2〜4週間程度）を置いてから申請してください。
また、AdSenseの不合格通知に記載された具体的な理由（『価値の低い広告枠』『コンテンツが存在しないサイト』など、文言によって原因が異なります）が分かれば、対策をさらに絞り込めます。
